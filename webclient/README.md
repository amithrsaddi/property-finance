# Web client

Static HTML + TypeScript UI for Property Finance.

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

UI: [http://localhost:5173](http://localhost:5173)

Configure API base URL in `public/config.js`.

## Pages

- `/` — sign in, register, forgot password
- `/dashboard.html` — portfolio overview
- `/properties.html` / `/property.html` — property management and detail
- `/rent.html` — rent tracking
- `/mortgages.html` — mortgages and payment views
- `/expenses.html` — property and additional expenses
- `/reports.html` — cash flow and profitability
- `/profile.html` — account settings
